GEETHALAKSHMI S — PORTFOLIO WEBSITE

Files:
- index.html: portfolio content and page structure
- style.css: responsive dark navy / cyan design
- script.js: mobile navigation and current footer year

How to preview:
1. Extract the ZIP file.
2. Open the geethalakshmi_portfolio folder.
3. Double-click index.html. It opens in your browser.
4. Keep all three files in the same folder.

Before publishing:
- Check that the GitHub and LinkedIn profile URLs are correct.
- If you want your own photo, replace the initials (GS) in the avatar area with an image.
- You can edit text directly in index.html.

This is a static front-end portfolio. It does not require a server or database.
